# 🍽️ URBAN KITCHEN — Restaurant Menu Web App

A modern, clean, professional restaurant menu web application built with vanilla HTML, CSS, and JavaScript. Features include category filtering, search, sorting, shopping cart with localStorage persistence, favorites, and a fully responsive design.

## 🎨 Color Theme

- **Emerald Green** — Primary color for elegance and freshness
- **Burnt Orange** — Accent color for warmth and appetite appeal

## ✨ Features

### Landing Page (Splash)
- **Sliding Content** — Auto-sliding messages with Emerald Green & Burnt Orange theme
- **URBAN KITCHEN** brand display with sliding animation
- **"Are You Hungry?"** headline with food image
- **"Check Out Menu"** button to enter the restaurant

### Core Features
- **Responsive Navigation** — Sticky navbar with logo, links, search, cart, and hamburger menu
- **Hero Section** — Attractive restaurant showcase with CTAs and floating info card
- **Explore Menu Button** — Smooth scroll to menu section with animation
- **View Specials Button** — Smooth scroll to specials section with animation
- **Menu** — Category filtering, live search, sorting, and professional food cards
- **Shopping Cart** — Add/remove items, quantity management, subtotal, drawer interface
- **Favorites** — Toggle favorites with localStorage persistence
- **Realistic Payment System** — Full payment flow with modal:
  - **PhonePe** 📱
  - **Google Pay** 💳
  - **Paytm** 🏦
  - **Credit/Debit Card** 💳
  - **Cash** 💰
  - **UPI** 📲
  - **Payment Modal** with progress bar and status updates
  - **Processing animation** with step-by-step feedback
- **Special Offers** — Promotional section with chef's special
- **About** — Restaurant story and values
- **Why Choose Us** — Key selling points with icons
- **Testimonials** — Customer reviews
- **Contact** — Form with validation and success toast
- **Toast Notifications** — User feedback for all actions
- **LocalStorage** — Cart and favorites persist across sessions

### UI/UX
- Modern, clean, minimal design
- Emerald Green & Burnt Orange color palette
- Generous whitespace and clear hierarchy
- Subtle shadows and smooth transitions
- Mobile-first responsive design
- Accessible (semantic HTML, ARIA labels, focus states)
